# 工作室录制模式：联调记录（2026-11-02）

代码：`app/kickpi_ui/k7_studio.{c,h}`（逻辑），`kickpi_ui_main.c` 的"工作"页签
（`work_*`），`k7_home` 的门铃订阅与 `k7_home_publish`，`k7_wake` 的
`k7_wake_set_offline`。

## 做法

- **布景**：开始时逐台记下设备状态，按预设下发：台灯开（补光），空调、新风、电视、
  饮水机关。本来就是目标状态的不发。
- **恢复**：结束时只恢复被我们改过、并且录制中没人再动过的设备。开始前状态未知的不恢复。
- **门口**：`home/studio/onair` 发 ON/OFF（retain）。录制中收到 `home/doorbell/event`，
  向 `home/doorbell/reply` 发代答文字，并打一个"门铃"点。不在录制时，门铃只在
  界面提示并念一句。
- **语音不出板子**：录制期间唤醒只做端点检测，不上传识别。唤醒原本没开的，
  录制时临时开（先切成不上传再开），结束后关回去。
- **噪声打点**：不在说话时，电平超过底噪 6 倍且不低于 1500，就记一个时间点，
  2 秒内的合并成一个。清单追加写进 `/data/studio/marks.txt`。
- **触发**：
  - 点"工作"页的按钮；
  - 说"你好 openvela，开始录制"（结束只能点屏幕，因为录制中不识别语音）；
  - 调试入口 `echo 1/0 > /tmp/k7-studio`。
